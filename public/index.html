Endpoint nhận dữ liệu:

Payload JSON:

{ "temperature": 35.2, "smoke": 14.5,
  "gas": 8, "flame": 0 }

Firmware: esp32/esp32_fire_guard.ino
DHT: GPIO4 · MQ-2: GPIO34 · Flame: GPIO18
Buzzer: GPIO23 · LED: GPIO2

Luồng: cảm biến → ESP32 → HTTP → SQLite & Socket.IO → dashboard. Đăng ký, bật/tắt và xoay token thiết bị qua API quản trị. Firmware phải gửi Authorization: Bearer DEVICE_TOKEN.
