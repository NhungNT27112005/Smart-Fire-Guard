💻 Endpoint HTTP POST cho ESP32

ESP32 của bạn sẽ gửi dữ liệu định kỳ đến URL Server Node.js bằng định dạng JSON:

URL: http://<SERVER_IP>:3000/api/sensor-data
Method: POST
Header: Content-Type: application/json
Payload JSON: 
{
  "temperature": 35.2,
  "smoke": 14.5,
  "gas": 8.0,
  "flame": 0
}

Phản hồi từ Server Node.js gửi lại ESP32:

{
  "success": true,
  "status": "bad",
  "alarmActive": true,
  "buzzerCommand": "BUZZER_ON"
}

📄 Bạn có thể tìm thấy file source code C++ hoàn chỉnh cho ESP32 trong thư mục esp32/esp32_fire_guard.ino của dự án này.
